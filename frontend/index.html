Platform Modules

10 Integrated AI Modules

Each module powered by state-of-the-art machine learning and NLP

Multi-Disease Prediction

PyTorch neural network trained on 4,920 real patient records across 41 diseases with 132 symptom features. Top-3 prediction with confidence scores.

PyTorch NN 4,920 rows

SHAP Explainability

KernelExplainer reveals which symptoms contributed most to each diagnosis. Fully transparent, research-grade XAI with visual feature importance charts.

SHAP Chart.js

Clinical NLP NER

SciSpacy-powered entity extraction identifies diseases, drugs, symptoms, lab values, and medical history from clinical free text.

SciSpacy 5 Entity Types

PDF Report Analyzer

Upload blood CBC, thyroid, liver, and kidney reports. Automatically extracts 20+ lab values, flags abnormals against WHO reference ranges, and generates summaries.

PyMuPDF OCR Fallback

Drug Safety Engine

Checks contraindications, pregnancy categories (A-X), drug-disease interactions, allergy alerts for 15+ common drugs. Never auto-prescribes — reference only.

Safety First 15 Drugs

Clinical RAG Pipeline

WHO/CDC guidelines stored in ChromaDB with sentence-transformer embeddings. Questions retrieve evidence → Gemini generates cited answers. Always shows sources.

ChromaDB Gemini API

Patient Chatbot

Conversational AI that answers health questions using RAG. Always shows citations and source chunks. Never answers without retrieved evidence.

RAG Chat Evidence-Based
